""" Renames direct attribute and group references on selected nodes. """

== Overview ==

This tool updates parameter, vex and python attributes or group names.
It updates their references not on the geometry directly.

== Quick Start ==

# In the current Network Editor, select the nodes you want to inspect.

# Click __Rename Attributes and Groups__ on the Labs shelf.

# Choose __Attributes__ or __Groups__. Enable __Inside Nodes__ only when you
  also want to inspect editable nodes contained by the selection.

# Choose a discovered name, then enter the new name and click __Preview__.

# Uncheck any edits you do not want, then click __Accept__.

== Supported References ==

The tool supports:

* Explicit attribute and group name fields with a proven owner class.

* Direct VEX bindings such as `f@name` when the Wrangle __Run Over__ class
  matches, and direct string arguments to supported VEX functions.

* Direct Python string arguments on proven `hou` receiver chains.

* Direct string arguments in supported HScript expression functions.

Aliases, `chs()` targets, macros, overloaded or qualified functions, dynamic
names, wildcard group operands, unknown expression languages, and ambiguous
group classes are not changed.

== Preview and Safety ==

Writes are verified and failed writes are restored when possible. Accepted
edits use one Houdini undo group, so ((CTRL)) + `Z` undoes the batch in one
step.

== Notes ==

Only the current Network Editor selection is searched by default. __Inside
Nodes__ adds nested editable nodes, but does not enter protected internals of
locked assets.

The final report lists applied, deselected, skipped, discovery, and failed
items.
