= Labs Biome Plant Scatter Import =

"""Import a biome plant scatter from SOPs to LOPs."""

A helper tool for bringing a plant scatter from a _Labs Biome Plant Scatter (Beta) SOP_ to LOPs with the correct settings for instancing.


@parameters

Path to Plant Scatter:
    #id: pathtoplantscatter
    The path to a _Labs Biome Plant Scatter (Beta) SOP_ to import into LOPs. 

Auto-fill Materials:
    #id: fillmaterials
    Import VOP materials as USD materials. If you include a global point material on the __Material__ parameter on _Labs Biome Plant Define SOP_, this will override any primitive materials set on the plant meshes.
