= Labs Impostor Camera Rig =

"""Sets up a camera rig to be used with the Labs Impostor Texture ROP."""

This node sets up a camera rig to be used with the [Labs Impostor Texture ROP|Node:out/labs--impostor_texture]. The tool sets up several cameras depending on the impostor type that gets rendered, including the lens shaders it needs.

NOTE: 
    Replaced by [Labs Impostor Baker SOP|Node:sop/labs--impostor_baker-1.0]. To be removed in Houdini 24.0.

@parameters
    Impostor ROP:
        This needs to point to the Impostor ROP.
