= Labs Turntable Lens =

"""A CVEX based lens shader used to generate impostors."""

This is a CVEX based lens shader used to generate impostors inside the [Labs Impostor Texture ROP|Node:out/labs--impostor_texture].

NOTE: 
    Replaced by [Labs Impostor Baker SOP|Node:sop/labs--impostor_baker-1.0]. To be removed in Houdini 24.0.

@parameters
    fixed_z:
	This toggle enables/disables the rendering of the geometry around the Y axis. (Z/Forward axis remains constant)
    rows:
	The number of rows generated for the impostor.
    columns:
	The number of columns generated for the impostor.
    camera_width:
	Sets the camera width of the lens shader. A larger camera width functions as a zoom.
