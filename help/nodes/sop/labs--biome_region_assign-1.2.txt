= Labs Biome Region Assign =

"""Delineates biome regions for the Biome Toolset workflow."""

Using Labs' Biome workflow, this node creates separate regions and apply defined biomes to the created regions. Biome names and attributes are defined using [Labs Biome Define SOP|Node:sop/labs--biome_define-1.1]. 

There are five distinct ways to create biome regions using this node:

__Image__: creates biome regions based on distinct colors from an image file, such as JPG, PNG, EXR, TIF file types, or a COP network.

__Geometry Attribute__: creates biome regions based on a specified primitive attribute on a proximal mesh. Supports string, integer, and float values, but float values will be clamped to integer values.

__Heightfield Layers__: creates biome regions based on density values of separate heightfield layers.

__PSD File__: creates biome regions based on separate layers of a Photoshop file. Unlike the __Image__ option, this is based on the presence of data on the specified layers and is not determined by color.

__Curves__: creates biome regions based on Houdini input curves. Options exist to separate curves by connectivity, a specified attribute, or through [Labs Biome Curve Label SOP|Node:sop/labs--biome_curve_label-1.1].


@parameters

    Display:
        #id: outputmode
        
        __Guide Geometry__: Visualizes the biome regions and their placement with color-coded geometry.
            
        __Final HeightField Layers__: Visualizes the actual output volumes fed into [Labs Biome Attributes to Terrain SOP|Node:sop/labs--biome_attributes_to_terrain-1.1].
            
    == Biome Regions ==

    Regions From:
        #id: source
        
        __Image__: creates biome regions based on distinct colors from an image file, such as JPG, PNG, EXR, TIF file types, or a COP network.
		
        __Geometry Attribute__: creates biome regions based on a specified primitive attribute on a proximal mesh. Supports string, integer, and float values, but float values will be clamped to integer values.
		
        __Heightfield Layers__: creates biome regions based on density values of separate heightfield layers.
		
        __PSD File__: creates biome regions based on separate layers of a Photoshop file. Unlike the __Image__ option, this is based on the presence of data on the specified layers and is not determined by color.
		
        __Curves__: creates biome regions based on Houdini input curves. Options exist to separate curves by connectivity, a specified attribute, or through [Labs Biome Curve Label SOP|Node:sop/labs--biome_curve_label-1.1].
            

    === Image Import Settings ===


    Image Source:
        #id: imgsrc
        
        __File__: Image source is an image file.
            
        __COP Network__: Image source is a COP network.
            
    Reload Image:
        #id: reloadimg
        Reloads the image specified in the file path and recooks the network.
        
    File Path:
        #id: imgfilepath
        File path to the specified image.
        
    COP Network Path:
        #id: coppath
        Network path to the specified COP network.
        
    Color Clusters:
        #id: clustercount
        Number of colors/regions to extract from the image. Will extract the largest concentrations of color first.
		
		
    === Advanced ===
    Sample Resolution:
        #id: sampleresmode
        
        __Source Image Resolution__: Uses the image's native resolution.
            
        __Specified Resolution__: Resamples the image into the specified resolution. Using a smaller resolution results in faster calculation times.
            
    Specified Resolution:
        #id: sampleres
        The resolution to resample the input image to in X, Y pixel dimensions.
    Sample Color Space:
        #id: samplecspace
        
        __Automatic__: Automatically selects the image color space.
            
        __Linear__: Uses a linear color space for the image.

    Cluster Iterations:
        #id: clusteriter
        Higher numbers give more accurate clustering but take longer to compute. See [Curve SOP|Node:sop/cluster] for more clustering information.
        
    Refine Region Borders:
        #id: refineclusters
        Consolidates nearby primitives into larger clusters. Reduces jagged and irregular region borders.
    Refine Iterations:
        #id: refineiter
        Number of iterations to attempt to consolidate stray primitive regions.
    Refine Distance:
        #id: refinedist
        Relative distance to search for primitives to consolidate.
    === Geometry Attributes ===

    Attribute Name:
        #id: attrname
        Name of the primitive geometry attribute to extract regions from. Uses unique attribute values to section out different region areas. Accepts string, integer, and float types, but float values will be clamped to integers to determine unique values.
    === Photoshop File ===

    File:
        #id: file
        Path to Photoshop file.
    Reload PSD:
        #id: reload
        Reloads the Photoshop file.
    === Curve Import Settings ===

    Generate Region Per:
        #id: curvegrouping
        
        __Connected Curves__: Generates regions based on each individual curve.
            
        __Unique Curve Primitive ID__: Generates regions based on unique curve attribute values.
            
        __Biome Curve Label__: Uses [Labs Biome Curve Label SOP|Node:sop/labs--biome_curve_label-1.1] to directly assign biome definitions to a curve or group of curves.
            
    Curve ID Attribute:
        #id: curveidattrib
        Name of the primitive geometry attribute to extract regions from. Uses unique attribute values to section out different region areas. Accepts string, integer, and float types, but float values will be clamped to integers to determine unique values.
    Create Curve Label Node:
        #id: createcurvehda
        Automatically creates a [Labs Biome Curve Label SOP|Node:sop/labs--biome_curve_label-1.1] and wires in necessary inputs that are shared with this node.

            

    === Region Assignment ===

    Recreate Region List:
        #id: generatecolors
        #id: hf_generatecolors
        Automatically generates a list of regions based on number of image clusters / unique attribute values / number of PSD layers / etc. based on the input type selected and auto-assigns biome definitions to each generated region.
    Reset Parameters:
        #id: resetimgparms
        #id: resetimgparms_hf
        When enabled, will reset the biome definitions assigned to each region.
    Match Size to Terrain:
        #id: matchsize
        #id: definitionmatch
        Scales the biome regions to fit within the boundaries of the input terrain. Disable to show manual transformation controls.
    Match Biome Definitions to Layers:
        #id: definitionmatch
        Matches Heightfield layers and biome definitions automatically if they are named exactly the same. Treats underscores and spaces as the same character.

    === Number of Regions ===

    Layer Name:
        #id: layer_name#
        #id: hflayername#
        Name of the layer to assign this region.
    Attribute Value:
        #id: attrvalue#
        The unique attribute value to assign this region.
    Biome Name:
        #id: img_bname#
        #id: hf_bname#
        Name of the Biome Definition to assign to this region.
    Sort Order:
        #id: img_bhierarchy#
        #id: hf_bhierarchy#
        The priority to assign to the associated region(s). A lower number will give the biome greater priority when resolving overlapping regions, putting it on top of regions with higher values. Biomes with the same value will have their biome attributes averaged.
    Visualization Color:
        #id: img_bcolor#
        Color applied to the __Guide Geometry__ for visualization purposes.
    === Advanced Photoshop Region Settings ===
    See [Labs Trace PSD File SOP|Node:sop/labs--trace_psd_file-2.0] for more information.

    Resample Step:
        #id: step#
        Distance in resampling the curve.
    Inline Point Threshold:
        #id: inlinepointremoval#
        Tolerance for removing inline points.
    Shrink UVs:
        #id: shrink_uvs#
        Shrinks the UVs on the curves in order to better sample the interior colors of the image. Sometimes the curves can sit too close to the border and the UVs pick out the color of the background.

        
    Shape:
        #id: op#
        Optionally, also __Shrink__ or __Expand__ the shape itself.
            
    Size:
        #id: size_psd#
        Distance of how much to __Shrink__ or __Expand__ the shape.
        

    == Output HeightFields ==

    Division Mode:
        #id: divisionmode
        Sets the volume resolution by number of samples or spacing distance.
    Grid Samples:
        #id: gridsamples
        The number of grid points along each axis, when __Division__ mode is __By Axis__.
    Grid Spacing:
        #id: gridspacing
        The space between grid points, in meters, when __Division__ mode is __By Size__.
    Size:
        #id: outputsize
        Sets the size of the output Heightfield if no terrain source is specified.
