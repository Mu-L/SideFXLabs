== Overview ==

_Labs Biome Configure SOP_ is a tool recipe to help users get started with the Biome toolset. This tool recipe creates a node network that generates a single-biome, mountain environment and simple plant scatter. _Labs Biome Configure SOP_ not only helps users learn how the nodes are wired together but it also helps save time setting up a biome pipeline. Just replace the input terrain and plant models to customize the setup and make it your own with little effort.      
    
== Understanding Labs Biome Configure ==

* The tool recipe can be found in the tab menu under "Labs/World Building/Biome" with the rest of the Biome tools.

* 'GENERATE_TERRAIN' controls the shape of the terrain. You can switch out this subnetwork with your own terrain to see how varying topography affects the plant scatter.  

* 'GENERATE_RIVER' creates geometry for the river that can also be input into the 4th input mask of 'biome_plant_scatter' to prevent plants from scattering in the river. 

* Replace the plant models with your own by editing the _Labs Biome Plant Define SOPs_. Under the __Species Variants__ tab, point the __Mesh Variants__ to your own files or operator paths.

* To learn more about the Biome toolset, visit the help pages for each tool contained in this network and dive into the example file linked below. The biome_demo.hip file contains many more examples and extensive notes.
