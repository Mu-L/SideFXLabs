= Labs ML CV Visualize Keypoints =

"""Visualizes keypoints and their connections."""


Provides a set of tools for visualizing keypoints and their connections, enabling a clear representation of types, skeletal structures, and mirrored points.


@parameters

    View Keypoints:
        #id: viskp
        Enables the calculation of ground truth (GT) for keypoint positions (both screen-space and global).
        Useful when  separating this node's functions and computing GT further  downstream.

    View Keypoint Type:
        #id: vistype
        Assigns colors to keypoints based on their `@kp_type` attribute, ensuring that keypoints of the same type share the same color.

    Keypoint Scale:
        #id: jointscale
        Specifies the path to the LOP node from which the camera primitive is sourced
        
    View Skeleton Connectivity:
        #id: visskel
        USD primitive path that points to the camera, used for obtaining screen space coordinates of the keypoints.
        
    Wire Width:
        #id: wirewidth
        Specifies the camera resolution. Defaults to `@res`, a PDG attribute created by the ROP Synthetic Data TOP.
        
    View Keypoint Swapable:
        #id: visswap
        Displays connection lines between points which are swappable mirrors of each other. for example, right elbow, left elbow.
        
    Wire Width:
        #id: radius
        Defines the thickness in meters of the swappable lines.
