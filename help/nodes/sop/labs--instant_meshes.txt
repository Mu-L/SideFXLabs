= Labs Instant Meshes =

"""Allows to run geometry through InstantMeshes and generate a quad mesh."""

This node takes in geometry through its primary input, and will then run it through the InstantMeshes algorithm to generate a new quad mesh.

NOTE: 
    This tool's functionality is replaced by the [Quad Remesh SOP|Node:sop/quadremesh]. To be removed in Houdini 23.0.

@parameters

    Cook:
        #id: execute
        Force a manual recook of the node.

    Manual Mode:
        #id: manual_mode
        Enabling this will prevent the node from recooking automatically on input geometry changes, or changes made to the parameters. Useful for freezing a result.

    == Mesh Options ==

    Desired Polygon Count:
        #id: poly_count
        Allows you to specify the desired polycount. By default this controls the number of generated points, but when Quad Dominant is toggled on, this controls the number of quads.
    
    Quad Dominant:
        #id: quad_dominant
        Generate a tri/quad dominant mesh instead of a pure tri/quad mesh.
    
    Deterministic:
        #id: deterministic
        Controls if the meshing should be deterministic.
    
    Crease Angle:
        #id: crease_angle
        Specifies the maximum generated Crease Angle used when deciding where to place edge loops.
    
    == Executable ==
    
    Instant Meshes:
        #id: instant_meshes_exe
        This should point to the executable of Instant Meshes, which you can download from the GitHub repo found when clicking __Download Instant Meshes__ button.
    
    Download Instant Meshes:
        #id: website
        This will open the browser and go to the Instant Meshes repo where you can download the required executables.
    
    == Advanced ==
    
    Instant Meshes Cache:
        #id: remeshed_tmp_file
        The location where the cache should be written to from Instant Meshes.
    
    Houdini Cache:
        #id: unremeshed_tmp_file
        The location where the cache should be written to from Houdini.
    
    Hide Dialog:
        #id: hide_instant_meshes_dialog
        Enabling this hides the command line dialog that pops up on Windows.
