= Labs ML CV Vector Data =

"""Creates Ground truth for 3D vectors."""


Creates Ground truth for 3D vectors to define metadata such as what direction an avatar is looking.

`Input 1` The geometry you want to add this GT to.

`Input 2` A single point with a vector attribute on it.


@parameters

    Source Point:
        #id: srcept
        Specifies the point index or the name of the group to which the vector point belongs.

    Visualize Vector:
        #id: visvector
        Toggle to enable visualization of the vector as a line within the scene geometry.

    ==== Dome Camera ====

    Camera Lop Path:
        #id: loppath
        Specifies the path to the LOP node from which the camera primitive is sourced.
        
    Camera Primitive:
        #id: primpath
        USD primitive path that points to the camera, used for obtaining
        screen space coordinates of the keypoints.
        
    Camera Resolution:
        #id: camres
        Specifies the camera resolution. Defaults to @res, a PDG
        attribute created by the `ROP Synthetic Data TOP`.

    ==== Output ====

    Vector Attribute Prefix:
        #id: vectorattrprefix
        Specifies the name of the vector attribute to be imported as ground truth.
