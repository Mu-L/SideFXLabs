= Labs Trace PSD File =

""" Generates Curves from Photoshop file layers. """

This tool is a wrapper around the [Trace SOP|Node:sop/trace] that works with PSD files with multiple layers. 

Generates curves from images that come from layers of a Photoshop file. The curves extracted depend on the Alpha value of the individual layers and not the color.

:note: 
	If the PSD file has an Alpha channel, ensure that there is one layer completely filled, such as the Background layer, or else there will be an error when importing the PSD file.

@parameters

    File:
        #id: file
        Path to the Photoshop (PSD) file.
    Reload PSD:
        #id: reload
        Refreshes the Photoshop file.
    Extract all Layers:
        #id: extractlayers
        Automatically load in all Photoshop file layers.
    == Layers To Extract ==

    Layer Name:
        #id: layer_name#
        Name of the extracted layer (case sensitive).
    === Advanced ===
        
    Resample Edge:
        #id: resampleamt#
        The maximum segment length of resulting edges.
    Dilate/Erode:
        #id: size#
        Amount to dilate or erode the specified layer.
