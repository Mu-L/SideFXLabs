= Labs Houdini Icon =

"""Generates a geometric representation of the Houdini icon."""

This node outputs a clean, procedural mesh of the Houdini icon.


@parameters

    Enable Extrusion:
        #id: extrude
        Enables extrusion of the icon geometry. When turned off, the icon is generated as flat geometry.
        
    Extrude Distance:
        #id: extrudedist
        Distance of the extrusion when __Enable Extrusion__ is turned on. Higher values produce a thicker, more pronounced three-dimensional icon.
