== Overview ==

_Labs Biome Configure Multibiomes SOP_ is a tool recipe to help users get started with the Biome toolset. This tool recipe builds a node network that generates a multi-biome, mountain environment and plant scatter. _Labs Biome Configure Multibiomes SOP_ not only helps users learn how the nodes are wired together but it also helps save time setting up a biome pipeline. Just replace the input terrain and plant models to customize the setup and make it your own with little effort.       
    
== Understanding Labs Biome Configure Multibiomes ==

* The tool recipe can be found in the tab menu under "Labs/World Building/Biome" with the rest of the Biome tools.

* 'GENERATE_TERRAIN' controls the shape of the terrain. You can switch out this subnetwork with your own terrain to see how varying topography affects the plant scatter.  

* 'HF_MASKS' creates the MOUNTAINS, LOWLANDS, and RIVERBED heightfield layers that control where the biomes will be placed. Replace this subnetwork and use terrain tools to generate or paint your own heightfield layers with names that match the _Labs Biome Define_ names. 

* 'GENERATE_RIVER' creates geometry for the river that can also be input into the 4th input mask of 'biome_plant_scatter' to prevent plants from scattering in the river. 

* Replace the plant models with your own by editing the __Labs Biome Plant Define SOPs__. Under the _Species Variants_ tab, point the _Mesh Variants_ to your own files or operator paths.

* To learn more about the Biome toolset, visit the help pages for each tool contained in this network and dive into the example file linked below. The biome_demo.hip file contains many more examples and extensive notes.
