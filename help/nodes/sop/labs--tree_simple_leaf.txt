= Labs Tree Simple Leaf =

"""Generates a simple leaf mesh for preview and procedural foliage workflows."""

This node creates a lightweight procedural leaf model intended for use in tree and foliage systems.

It is primarily designed for visualization, look development, and rapid prototyping, and can be connected to the custom leaf input of the [Labs Tree Leaf Generator|Node:sop/labs--tree_leaf_generator] to provide leaf geometry for procedural tree setups.

The node provides controls for overall size, segmentation, profile shape, folding, bending, point jitter, and color.

@parameters

    == Size and Segments ==

    === Size ===

    Leaf Size:
        #id: leaf_size
        Uniform scale applied to the leaf.

    Length:
        #id: dist
        Length of the leaf.

    Width:
        #id: width
        Width of the leaf.

    === Segments ===

    Length Segments:
        #id: points
        Number of edges along the leaf length.

    Z Bias:
        #id: pos_bias2
        Adjusts the spacing of segments along the leaf length.

    Width Segments:
        #id: cols
        Number of edges across the leaf width.

    X Bias:
        #id: pos_bias
        Adjusts the spacing of segments across the leaf width.

    == Shape ==

    === Shape Profile ===

    Method:
        #id: shape_method
        Method used to generate the leaf mesh.

    Leaf Profile:
        #id: leaf_profile
        Profile defining the outer leaf shape.

    === Folding ===

    Folding Amount:
        #id: folding_amount
        Offset applied to the center fold of the leaf.

    Folding Profile:
        #id: folding
        Controls fold strength along the leaf length.

    === Bend ===

    Bend:
        #id: bend
        Bend angle applied to the leaf.

    Bend Profile:
        #id: bend_profile
        Controls bend strength along the leaf length.

    == Point Jitter ==

    Scale:
        #id: scale
        Strength of the point jitter deformation.

    Seed:
        #id: seed
        Random seed used for point jitter variation.

    == Color ==

    Leaf Color:
        #id: color
        Color ramp applied along the leaf length.

    Stem Color:
        #id: stem_color
        Color ramp applied along the center fold of the leaf.

    Mix:
        #id: mix
        Blends the stem color with the leaf color.
