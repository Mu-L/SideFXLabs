= Labs Tree Leaf Generator =

"""Generates leaves on procedural tree branches."""

The Labs Tree Leaf Generator SOP creates leaf geometry on branches generated by the [Labs Tree Branch Generator|Node:sop/labs--tree_branch_generator-1.2] or [Labs Tree Branch Placer|Node:sop/labs--tree_branch_placer-1.1].

Leaves are distributed along branch curves and can be scaled, oriented, pruned, and procedurally varied to create natural foliage patterns.

Leaf geometry can be generated internally as simple cards or supplied through custom leaf inputs such as the [Labs Tree Simple Leaf|Node:sop/labs--tree_simple_leaf].

The node also supports instancing workflows for large trees where performance is critical.

@parameters

    Tag:
        #id: tag
        Name used to create a group and attribute identifying the generated leaf geometry or curves.  
        By default this matches the node name.

    Branch on Group:
        #id: branch_group
        Restricts leaf generation to the specified curve group.  
        When empty, leaves are generated on curves from the previous branch level.

    Delete Previous Levels:
        #id: del_prev
        Deletes geometry and curves from all previous branch levels.

    Randomize:
        #id: seed
        Random seed used for procedural variation.

    Pack and Instance:
        #id: pack2
        Packs and instances leaf geometry for improved performance.  
        This disables editing of tropism and noise but significantly speeds up large trees.

    Treat as Atlas:
        #id: atlas
        Enables atlas-based leaf generation.  
        When using atlas-based textures (for example from the Quixel Atlas Splitter), multiple leaf cards are generated from the atlas and randomly scattered.

    Use Variant Attribute:
        #id: use_variant
        Enables scattering of multiple leaf variations.  
        Each leaf type must include an integer attribute named **variant** starting at 0.

    == General ==

    === Placement ===

    Leaf Node Distance:
        #id: num_lat
        Distance between leaf placement points along the branch.

    Use Distribution Ramp:
        #id: distrib_ramp
        Enables distribution of leaf points using a ramp.

    Distribute By:
        #id: distrib_mode
        Attribute used to drive leaf distribution.

        <p>__Length of parent__: Distributes by parent curve length.</p>
        <p>__Radius of parent__: Distributes by parent radius.</p>
        <p>__Height of parent__: Distributes by parent height.</p>

    Distribution Ramp:
        #id: distribution_ramp
        Controls leaf density based on the selected distribution attribute.

    Up Vector:
        #id: up_vec
        Vector used to orient generated leaves.

        <p>__None__: Does not apply a specific orientation vector.</p>
        <p>__Parent__: Uses the parent tangent direction.</p>
        <p>__Custom__: Uses the vector specified in __Custom Up__.</p>

    Custom Up:
        #id: custom_up
        Custom vector used when __Up Vector__ is set to _Custom_.

    Branching Pattern:
        #id: lat_phy_angle
        Rotation around the branch used to distribute leaves.

        <p>__137.5 degrees__: Uses a phyllotactic pattern.</p>
        <p>__90 degrees__: Places leaves at right angles.</p>
        <p>__180 degrees__: Alternates leaves on opposite sides.</p>
        <p>__Alternate__: Places one leaf per branch point.</p>
        <p>__Opposite__: Places two mirrored leaves per branch point.</p>
        <p>__Radial__: Places a user-defined number of leaves around each point.</p>

    Randomize Leaves Per node:
        #id: lat_branches_rand
        Enables random variation in the number of leaves generated per point.

    Leaves per node:
        #id: branches_per_node
        Number of leaves created at each placement point.

    Min Leaves Per Node:
        #id: lat_branches_min
        Minimum number of leaves generated per point when randomization is enabled.

    Max Leaves Per Node:
        #id: lat_branches_max
        Maximum number of leaves generated per point when randomization is enabled.

    Uniform Scale:
        #id: lat_length
        Uniform scale applied to leaf geometry.

    Uniform Scale Variation:
        #id: lat_length_rand
        Random variation applied to leaf scale.

    Size:
        #id: size
        Base size multiplier applied to leaves.

    Size Offset:
        #id: radius_strength
        Offset applied to leaf size based on branch attributes.

    Size Ramp:
        #id: lat_length_ramp
        Controls leaf placement and size along the branch.

    Inherit Branch Radius:
        #id: inherit_radius
        Scales leaf size based on the parent branch radius.

    Inherited Radius Profile:
        #id: inherit_radius_profile
        Controls how parent radius influences leaf size along the branch.

    === Prune ===

    Random Threshold:
        #id: del_threshold
        Randomly removes leaves based on a threshold value.

    Prune by Light Availability:
        #id: light_prune
        Removes leaves based on simulated light exposure.

    Light Source:
        #id: light_source
        Object or light used to evaluate illumination.

    Light Direction:
        #id: light_prune_dir
        Direction used for light evaluation when no source object is provided.

    Visualize:
        #id: light_vis
        Displays a visualization of light exposure on leaves.

    Method:
        #id: light_prune_method
        Method used to evaluate light exposure.

    Threshold:
        #id: light_prune_amount
        Minimum light value required for leaves to remain.

    Bias:
        #id: light_prune_bias
        Bias applied to the light direction calculation.

    === Advanced ===

    Accurate Leaf Placement:
        #id: leaf_placement
        Moves leaf placement points toward the outer surface of the parent branch.

    Offset From Branch:
        #id: offset
        Offsets leaves away from the branch surface.

    Grid Behavior:
        #id: grid_
        Controls how leaves interact with the construction grid.

        <p>__Constrain__: Snaps leaves to the grid plane.</p>
        <p>__Clip__: Deletes leaves sections below the grid plane.</p>
        <p>__None__: Does not modify leaves when they intersect the grid.</p>

    Normal Method:
        #id: normals
        Method used to compute leaf normals.

        <p>__Default__: standard polygon normals.</p>
        <p>__Spherical__: normals projected from a surrounding sphere.</p>
        <p>__Origin__: normals pointing away from the world origin.</p>

    == Orientation ==

    Roll:
        #id: roll
        Rotates leaves around their local axis.

    Use Roll Ramp:
        #id: roll_ramp
        Enables roll adjustment along the branch using a ramp.

    Roll Profile:
        #id: roll_profile
        Controls roll variation along the branch.

    Yaw:
        #id: yaw
        Rotates leaves around the vertical axis.

    Randomize Yaw:
        #id: randomize_yaw
        Random variation applied to yaw rotation.

    Use Yaw Ramp:
        #id: yaw_ramp
        Enables yaw variation along the branch using a ramp.

    Yaw Profile:
        #id: yaw_profile
        Controls yaw variation along the branch.

    Pitch Angle:
        #id: pitch_angle
        Rotates leaves around the forward axis.

    Randomize Pitch:
        #id: randomize_pitch
        Random variation applied to pitch.

    Use Pitch Ramp:
        #id: pitch_ramp
        Enables pitch variation along the branch using a ramp.

    Pitch Profile:
        #id: pitch_profile
        Controls pitch variation along the branch.

    Twist:
        #id: twist
        Rotates leaves around their longitudinal axis.

    Randomize Twist:
        #id: randomize_twist
        Random variation applied to twist rotation.

    Use Twist Ramp:
        #id: twist_ramp
        Enables twist variation along the branch using a ramp.

    Twist Profile:
        #id: twist_profile
        Controls twist variation along the branch.

    == Tropism ==

    Tropisms simulate environmental forces that influence leaf orientation.

    === Bend Along Parent ===

    Enable:
        #id: enable_bend
        Enables bending relative to the parent branch.

    Strength:
        #id: bend_strength
        Strength of bending along the parent branch.

    Falloff:
        #id: bend_ramp
        Controls bend influence along the leaf.

    === Gravitropism ===

    Enable:
        #id: enable_grav
        Enables gravity-based bending.

    Direction:
        #id: grav_dir
        Direction used to simulate gravity.

    Strength:
        #id: grav_strength
        Strength of gravity influence.

    Falloff:
        #id: grav_ramp
        Controls gravity influence along the leaf.

    === Phototropism ===

    Enable:
        #id: enable_light
        Enables growth toward light.

    Direction:
        #id: light_dir
        Direction of the light source.

    Strength:
        #id: light_strength
        Strength of light influence.

    Falloff:
        #id: light_ramp
        Controls light influence along the leaf.

    == Noise ==

    Adds procedural variation to leaf orientation and deformation.

    Enable:
        #id: enable_line_noise
        Enables noise deformation.

    Intensity Ramp:
        #id: line_noise_intensity_ramp
        Controls noise strength along the leaf.

    ==== Primary ====

    Curl noise used for primary curve variation.

    Noise Type:
        #id: type
        Type of curl noise used.

    Intensity:
        #id: line_noise_size
        Strength of the primary noise deformation.

    Frequency:
        #id: line_noise_size
        Scale of the primary noise.

    Roughness:
        #id: line_noise_rough
        Adds fractal detail to the primary noise.

    Step Size:
        #id: h
        Sampling resolution used to evaluate the noise.

    Randomize Offset:
        #id: line_noise_rand
        Randomizes the noise offset using the seed.

    Offset:
        #id: line_noise_offset
        Offsets the noise pattern in space.

    ==== Secondary ====

    Secondary anti-aliased noise layer.

    Intensity:
        #id: line_noise_amount2
        Strength of the secondary noise.

    Frequency:
        #id: line_noise_size2
        Scale of the secondary noise.

    Roughness:
        #id: line_noise_rough2
        Adds detail to the secondary noise.

    Randomize Offset:
        #id: line_noise_rand2
        Randomizes the secondary noise offset.

    Offset:
        #id: line_noise_offset2
        Offsets the secondary noise pattern in space.

    == Resolution ==

    Rows:
        #id: rows
        Number of edge rows on generated leaf cards.

    Columns:
        #id: cols
        Number of edge columns on generated leaf cards.

    == Visualization ==

    Enable Visualization Color:
        #id: vis_toggle
        Enables viewport color visualization.

    Color:
        #id: color
        Color used for visualization.
