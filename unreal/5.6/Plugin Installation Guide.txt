1. Make sure there is a "Plugins" folder next to the Content folder in your Unreal project directory. If the "Plugins" folder does not already exist, create one. (Your project directory is where the .uproject file is located.)

--- IMPORTANT ---
The latest SideFX Labs for Unreal Plugin requires binaries to run. The plugin with pre-compiled binaries (only available for each production release) can be downloaded from https://github.com/sideeffects/SideFXLabs/releases. Alternatively, you can build the plugin yourself (see the Building From Source section below). 

If you want to use the legacy version of the plugin that does not contain or need binaries, go directly to step 4.
-----------------

2. To get the latest plugin with pre-compiled binaries, go to https://github.com/sideeffects/SideFXLabs/releases, and find the a production release that you would like to use. Under Assets, download the zip file with the name "SideFXLabs-H**.*.***.zip". Once the download has finished, unzip the file and you will have a SideFX Labs Package. In the package, the SideFX Labs Unreal Plugin for your specific Unreal version can be found in the directory /unreal/<Unreal version>/.

3. Copy the "SideFX_Labs" folder inside the OS folder of your choice ("Mac" or "Win64"), and then go directly to step 5.

4. Copy the "SideFX_Labs" folder inside the "Legacy" folder.

5. Paste the copied "SideFX_Labs" folder into the "Plugins" folder mentioned in step 1.

6. Your plugin is now intalled to your project. Launch your Unreal project and you should immediately have access to the Material Functions, Scripted Actions, etc. provided by the plugin. (With the project open, you can verify the plugin is successfully enabled by searching for "SideFX Labs" in Edit > Plugins.)


Alternative Installation Location:

Installing the plugin to your project directory is recommended if you are working within a team where the project files are shared/source-controlled but the engine files are not.

Alternatively, you can install the plugin to the engine directory, e.g.: C:\Program Files\Epic Games\UE_5.0\Engine\Plugins\FX\<Paste the SideFX_Labs folder here>. This may be more convenient if you are working alone on multiple different projects.



Building From Source:

1. Open the Houdini Launcher and open Command Line Tools. This can be found by clicking the drop down arrow left of the Launch button and right of the gear icon for any Houdini version under the Houdini Versions section.

2. Once the terminal has opened type the command   hython path/to/builder.py 
   The builder.py script is in the same folder as this Plugin Installation Guide.txt file. 

3. After the Unreal Build Tool window appears, fill out the parameters and click the Start Build button. 

   Build Platform:     The platform the plugin will be built for.
   Build Script:       The path to the Unreal build script. On Windows this will be a .bat file and on Linux/Mac it will be a .sh file. These files are found in the Unreal Engine installation directory in Engine/Build/BatchFiles/
   Plugin File:        The path to the .uplugin file found in the SideFXLabs folder.
   Build Path:         The path to the directory the plugin will be built to.
